# constellation-art-ndeyeamifall
 MA DEMARCHE Le Cheval Complet 🐴✨
 c'est la silhouette complète d'un cheval (museau, pattes, dos, crinière, queue) à partir d'une liste de coordonnées, en simulant l'apparence d'une constellation.
 j'ai commence par définir les points — Une liste de coordonnées (x, y) représente les points clés de la silhouette du cheval (nez, mâchoire, pattes avant/arrière, dos, crinière, oreilles) pour que ca donne l'apparence d'un cheval .
 ensuite j'ai relié les points — Le stylo Turtle parcourt chaque coordonnée dans l'ordre et trace un trait continu.
Et j'ai aussi placer les étoiles — À chaque point, un petit cercle doré (dot) est dessiné pour simuler une étoile de constellation.
et pour la couleur c du Fond bleu nuit (#1a1a2e), trait rose/violet (#DA29B3) et étoiles dorées pour l'effet constellation.
